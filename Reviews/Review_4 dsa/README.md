# DSA Test

A collection of Data Structures and Algorithms exercises and unit tests implemented in C# targeting .NET 10.

Deliverables in this repository:

- Source code: DSA Test/ (core classes and data-structure implementations)
- NUnit tests: Testing/ (unit tests validating behavior)
- Design: DSA Test/DESIGN.md (architecture and module responsibilities)
- Complexity analysis: DSA Test/COMPLEXITY.md (time and space complexity of main algorithms)
- README: this file (getting started and links)

## Requirements
- .NET 10 SDK
- Visual Studio 2026 (recommended) or any compatible IDE

## Getting Started
1. Open the solution: `DSA Test.slnx`.
2. Restore and build: `dotnet build "DSA Test.slnx"`.
3. Run tests: `dotnet test "DSA Test.slnx"` or use Test Explorer in Visual Studio.

## Project Structure
- `DSA Test/` — Core source files (Ecommerce models, cart, search, sort, promo carousel, etc.).
- `Testing/` — NUnit unit tests covering the implementations.
- `DSA Test/DESIGN.md` — Design and architecture notes.
- `DSA Test/COMPLEXITY.md` — Complexity analysis for key operations.
